# Uso de IA en La casita de los hechizos

## ChatGPT y Codex

Se usaron como apoyo para explorar la idea de un juego con gestos, revisar el código en Python y preparar la documentación. En el código presentado, la asistencia incluyó reunir la captura y la detección en [vision.py](vision.py), trasladar tiempos y metas a [ajustes.py](ajustes.py) y documentar el arranque y las reglas.

Consignas de trabajo relevantes, resumidas a partir del proceso:

- Preparar La casita para el Obligatorio 2. Usar la cámara como control de las partidas, separar OpenCV en vision.py y resolver la pérdida de seguimiento.
- Revisar las reglas de las cuatro aventuras, documentar sus funciones y conservar sus tiempos y metas al moverlos a ajustes.py.

Estos dos puntos resumen el trabajo de revisión. El historial de Git registra los cambios correspondientes.
